# estudos-neville-goddard
Projeto de estudos sobre os ensinamentos e metodologia de Neville Goddard utilizando NotebookLM.

## Objetivo

Este projeto tem como objetivo estudar os ensinamentos e a metodologia de Neville Goddard utilizando o NotebookLM como ferramenta de organização e aprendizado com Inteligência Artificial.
---

# Contexto do Projeto

O estudo foi desenvolvido para compreender os principais conceitos ensinados por Neville Goddard sobre imaginação, consciência, visualização e manifestação da realidade.

# Miniguia de Estudos

## Resumo

Neville Goddard ensinava que a imaginação humana possui poder criativo e influencia diretamente a realidade percebida.

# Glossário

## SATS
Estado semelhante ao sono usado para visualização.

## Consciência
Estado mental que influencia experiências.

## Imaginação Criativa
Capacidade de criar mentalmente situações desejadas.
